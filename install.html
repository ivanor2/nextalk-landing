Руководство по установке узла NexTalk

Поднимите собственный независимый сервер передачи сообщений менее чем за 15 минут.

Системные требования

Среда выполнения
Node.js 20+ (LTS)
База данных
Встроенная SQLite
Память и диск
512 МБ ОЗУ · 5 ГБ SSD
Сетевое соединение
HTTPS / WSS (SSL)

Пошаговая инструкция по запуску

1

Скачайте исходный код узла

Клонируйте официальный репозиторий или загрузите архив с исходным кодом узла:

git clone https://github.com/ivanor2/nextalk-node.git node-server && cd node-server
2

Установите зависимости

Узел использует легковесные библиотеки (ws, dotenv, sqlite3). Отдельный сервер MySQL не требуется:

npm install
3

Настройте файл конфигурации (.env)

Создайте конфигурационный файл на основе примера и укажите публичный адрес:

cp .env.example .env
PORT=3001
NODE_NAME="Мой личный узел"
AUTH_SERVER_URL=https://auth.nextalk.net
PUBLIC_WS_URL=wss://my-node.example.org
4

Запустите узел

Запустите сервер в фоновом режиме через менеджер процессов PM2 или системную службу systemd:

pm2 start server.js --name nextalk-node && pm2 save

Заявка на регистрацию узла в каталоге

После успешного запуска узла заполните форму, чтобы администратор сети проверил доступность и добавил ваш сервер в глобальный каталог пользователей.

Сервер должен быть доступен по зашифрованному протоколу SSL (порт 443 / WSS)
Для связи и экстренных уведомлений в случае потери связи с узлом
Ключ генерируется автоматически при первом запуске в директории keys/public.pem
